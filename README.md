# p62_psychosis
This is a data depository for the following publication: 


Kun Yang, Koko Ishizuka, Toshifumi Tomoda, Akira Sawa. Aberrant aging-associated p62 autophagic cascade 
in biopsied olfactory neuronal cells from patients with psychosis. <b><i>Schizphrenia</i></b> (2025)


## Data
The "data" folder contains p62 protein/mRNA levels from olfactory neuronal cells (ONCs) and lymphoblasts (LBs) of healthy controls and patients with ealry-stage psychosis (onset within 2 years).
* database_ONC.csv -- protein data from ONCs
* database_LB.csv -- protein data from LBs
* database_mRNA_ONC.csv -- mRNA data from ONCs   


## Analysis 
* 01_stats_ONC.R -- basic statiscal analysis of p62 protein levels from ONCs
* 01_stats_LB.R -- basic statiscal analysis of p62 protein levels from LBs
* 01_stats_mRNA_ONC.R -- basic statiscal analysis of p62 mRNA levels from ONCs
